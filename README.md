# RentalCar# 🚗 RentalCar

A car rental web application built with **Next.js, React, and TypeScript**.

## Features

- Browse available rental cars.
- Filter cars by brand, price, and mileage.
- Load more cars with pagination.
- View detailed car information.
- Submit booking requests.
- Form validation and notifications.
- Responsive design.

## Technologies

- Next.js 15
- React 19
- TypeScript
- TanStack Query
- Axios
- Formik & Yup
- CSS Modules
- React Hot Toast

## API

[GoIT Car Rental API](https://car-rental-api.goit.study/api-docs/)

## Installation

```bash
git clone YOUR_REPOSITORY_URL
cd rentalcar
npm install
```

Create `.env.local`:

```env
NEXT_PUBLIC_API_URL=https://car-rental-api.goit.study
```

Run the project:

```bash
npm run dev
```

Open http://localhost:3000
